# Misi-Pahlawan-Alpha
Misi Pahlawan Alpha-Dunia Borneo ialah permainan RPG pendidikan 2D yang membawa pemain meneroka dunia fantasi Nusantara melalui 46 misi pembentukan karakter selama setahun. Menampilkan lima wira, cabaran IQ dan EQ, nilai murni, sistem pengalaman (XP), ganjaran dan pengembaraan interaktif beridentitikan budaya Sarawak.
